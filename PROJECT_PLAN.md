# Flight Agent Evaluator — Project Plan & Roadmap

## Overview
Flight Agent Evaluator is a rigorous, reproducible evaluation platform for aviation AI agents.

## Roadmap

| Stage | Milestone | Status |
|---|---|---|
| Stage 0 | Evaluator correctness | Complete |
| Stage 1 | Real model-driven agent, deterministic baselines and replayable model exchanges | Complete |
| Stage 2 | Trajectory constraint graph and multiple-valid-path scoring | In Progress |
| Stage 3 | Failure-mode classification and evidence attribution | Planned |
| Stage 4 | Calibrated LLM judge and human-labelled validation | Planned |
| Stage 5 | Simulated approval, booking and idempotent mutation environment | Planned |
| Stage 6 | Multi-model benchmark and evaluator-validity experiments | Planned |
| Stage 7 | Public held-out benchmark and reproducible results | Planned |

## Methodological Focus
Evaluating agent trajectories against versioned constraint graphs supporting multiple valid solution paths rather than enforcing single golden traces.
